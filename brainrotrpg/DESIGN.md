# Brainrot RPG design checkpoint

A light grimoire in golden fields and mystical ruins. Original approved scene art is presentation, not a real campaign location. Preview characters and rolls are explicitly fictional.

Cormorant Garamond for display text, Manrope for game facts. Party sheets, resolved roll history and lore are text-first. Recorded dice replay their actual stored result, never reroll. Scroll choreography, scene drift and die motion respect reduced motion; pause remains available on phones. No scroll trapping or manual card-download button.

Character and event APIs provide revision-bound SVG. A strict inert PNG adapter applies the same local golden scene behind a readable light overlay. There is no browser renderer, network fetch or credential in this image stage. Long names and class descriptions wrap; clipped text is marked as an excerpt and points readers to the campaign record. API execution and attachment delivery still require live qualification.

Actual desktop and phone pixels have been inspected and independently reviewed. No automated design score is claimed. One deliberate scene is reused rather than inventing campaign art for every action. The dark deployed Worker is not a public site or primary game record.

## Map checkpoint (feature branch)

Two rendering regimes: live campaign data shows an uncharted chart with recorded markers only (exploration-honest, no invented geography); demo preview shows a deterministic 3D biome terrain with trees and grass as clearly fictional scenery. Marker icons are locally drawn illustrations (ruin, dungeon, wilds, settlement, water, mystic, party banner, boss skull; defeated bosses desaturated and cracked). Boss record images are deterministic seeded SVG cards passing the inert PNG renderer. Camera drift respects reduced motion and the existing pause control.
